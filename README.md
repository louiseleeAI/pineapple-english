# 菠萝英语精听

英语播客与 Newsletter 的精听精读台，做成 Obsidian 插件。

一边听一边看逐句字幕：**点哪句播哪句**、单句循环、双击查词、跟读录音，听完的句子进错题本，生词按间隔重复复习，每天的学习时长自动记进打卡日历。音频、字幕、录音、笔记全部留在你的库里。

## 装法

**推荐：社区插件市场** —— Obsidian → 设置 → 第三方插件 → 浏览 → 搜 `Pineapple English Listening` → 安装并启用。首次审核通过、目录同步后即可搜到；在此之前可用下面的手动安装，或用 BRAT 填仓库地址公测。

**手动安装**

1. 从 Release 下载 `main.js`、`manifest.json`、`styles.css` 三件，放进 `你的库/.obsidian/plugins/pineapple-english/`（或解压整个 zip 包）
2. Obsidian → 设置 → 第三方插件 → 关闭「限制模式」→ 刷新 → 打开「菠萝英语精听」
3. 左侧栏出现耳机图标，点开即用

> 市场安装只下载上述三件套，核心功能全部可用；本地转写等可选增强的说明见「网络、权限与可选增强」章节。

首次打开可点「发现 / 添加订阅」：顶部两个按钮，「一键订阅核心 4 个」最快，「订阅全部 16 个」可一次加满英语学习源（其中 1 个音频经境外跳转、大陆多数网络连不上）；下面还按分组列了短新闻、科技、自带逐字稿的节目和 Newsletter。

> **首次打开会弹一页「欢迎使用」**：说明核心功能开箱即用、逐句文本从哪来、以及可选增强（本地转写 / 跟读打分加速）去设置页哪里配。点「开始使用」即可关掉；以后不再弹。自动订阅时若某个源暂时连不上（大陆网络常见），不会报错打断你——欢迎页会如实告诉你成功几个、失败几个，去「发现订阅」挑标注「大陆可直连」的源即可。

## 三栏布局

| 栏 | 内容 |
|---|---|
| 左 | 订阅源、分组、全部 / 未读 / 收藏筛选、搜索 |
| 中 | 该源的文章/单集列表 |
| 右 | 播放条 + 逐句字幕（或原文阅读），下方是跟读练习区 |

窗口变窄会自动收成两栏、单栏。

## 听

- **单击句子** → 从这句开始播；**双击句子** → 从这句循环
- 空格播放/暂停、← → 退/进 15 秒、↑ ↓ 上一句/下一句
- 0.65x – 1.75x 变速
- **单句循环**：反复听当前句，句尾自动跳回，点别的句子就换目标
- **自动连播**：句尾自动进下一句，可以闭眼听完整集（和单句循环互斥；到句尾才推进，拖进度条不会乱跳）
- **字幕全文搜索**：字幕区顶部搜索框，输入即过滤、回车跳到下一处命中；只在你有字幕的这一集里搜
- **跟随滚动**：播到哪句滚到哪句，只滚字幕区不乱动整页；你手动滚了就暂停跟随 4 秒
- 播完一句自动标记「已读」，列表里不再算未读

## 记

- **双击单词** → 音标、释义、例句、发音；一键加入生词本（自动带上下文和来源）
- **生词本**：间隔重复复习（1/2/4/7/15/30 天），空格揭晓，1 忘了 / 2 记得；整表同步到 `{笔记目录}/生词本.md`，可导出 CSV / Anki
- **易错词**：复习答错的词自动进「易错」清单，答错 2 次以上的一直留着
- **错题本**：句子右侧 ⚑ 标记没听懂/读错的句子，可从清单跳回原句重听，过关后归档，同步到 `{笔记目录}/错题本.md`
- **打卡统计**：连续天数、今日/本月/累计时长、本月篇数、最近 30 天柱状图、最近 12 周热力图；本月时长会自动换算成「几集节目 / 几趟京沪高铁」（只算真正播放的时间，拖进度条不算）
- **收听统计**：常听节目排行、24 小时收听生物钟环形图（晨读者 / 夜航者）、小发现（听得最久的一天、凌晨还在听哪一集、哪集听了不止一遍）。全部在本地统计，不上传
- **盲听自测**：统计面板点「测一次」，随机抽 3 句**隐藏字幕**播放，听完自评「听懂 / 半懂 / 没懂」，按周记成「不开字幕听懂多少」。约 40 秒一次，同一集每天只记一次
- **跟读录音 + 打分**：选句 → 录音 → 自动裁掉首尾静音存 WAV；配好本地转写后，录完会自动识别你说的话，跟原句做词级对齐，给你**覆盖率分数**并标出「漏了哪些词、多念了什么」。首句约 3–4 秒，之后每句 1 秒左右（常驻识别进程），分数会记在「练 N」徽章旁边。设置里打开「**跟读达标才进下一句**」后，低于 70 分会停在这句重练，达到 70 分自动进下一句；只听不跟读时不受影响
- **错题本**：句子右侧 ⚑ 标记，清单里可**连播**这一批句子（不用回原集），逐句过关
- **笔记**：整篇精读笔记、逐字稿导出、写入今日日记
- **引用即笔记**：句子右侧「引」按钮 → 把这句连同来源、集名和**可点击的时间戳**写进 `{笔记目录}/英语精听引用.md`；点笔记里的时间戳会跳回原句接着听

## 逐字稿从哪来

按顺序尝试，全部失败才提示手动粘贴：

1. 播客 RSS 里的 `podcast:transcript`（优先 VTT）
2. 节目网页里的逐字稿（同域限制，识别时间戳节点，排除目录/章节列表）
3. 本地 Whisper 转写（`faster-whisper`，base.en 模型，约 10 倍速，完全离线）
4. 手动粘贴 SRT / VTT，或用整篇原文按句长估算时间轴

估算出来的时间轴会明确标「≈ 估算」，不会假装是真的时间戳。

## 本地转写（可选）

设置页最上面的「可选增强状态」里有 **3 步配置**，每步都带按钮（复制安装命令 / 下载脚本 / 模型下载页），照着点完再点一次「检测」。手动做也可以：

1. **装依赖**：`pip install faster-whisper`（Python 3.10+，建议独立虚拟环境）
2. **放脚本**：下载 [extras/transcribe.py](https://raw.githubusercontent.com/louiseleeAI/pineapple-english/main/extras/transcribe.py)，存到任意文件夹
3. **下模型**：`base.en`（约 145MB），准备好含 `model.bin` 的文件夹

然后在设置页填三个路径：

- 转写脚本目录（放 `transcribe.py` 的文件夹，例 `D:/asr`）
- Python 解释器（装了 `faster-whisper` 的 `python.exe`，例 `D:/asr/.venv/Scripts/python.exe`）
- 模型目录（含 `model.bin`，例 `D:/asr/models/base.en`）

不填也能用，只是没字幕的节目要手动粘贴 SRT/VTT。

## 数据备份

生词、错题、打卡统计、订阅全在一个 `data.json` 里，md 那几份只是单向副本。所以：

- 每次启动后自动备份一次到 `.obsidian/plugins/pineapple-english/backups/`，6 小时内只做一次，保留最近 7 份
- 设置页「立即备份」可以手动存一份
- 设置页「导出学习数据」把生词、错题、统计、设置导成 JSON 到笔记目录，换机器或长期留存用

## 快捷键

命令面板里搜「菠萝」有四个命令，可以自己绑快捷键：

| 命令 | 作用 |
|---|---|
| 播放 / 暂停（当前句） | 不用点面板 |
| 下一句 / 上一句 | 配合循环逐句过 |
| 切换单句循环 | 反复听当前句 |
| 切换自动连播 | 句尾自动进下一句 |

## 网络、权限与可选增强（社区目录披露）

### 网络请求：全部由你的操作触发，没有后台轮询

| 用途 | 目标 | 触发时机 |
|---|---|---|
| 订阅刷新、文章正文抓取 | **仅你手动添加的** RSS / 网页地址 | 点刷新、打开文章 |
| 音频流 | 订阅源 `enclosure` 里的音频 CDN | 点播放 |
| 查词：音标 / 英文释义 | `api.dictionaryapi.dev` | 双击单词 |
| 查词兜底 | `dict.youdao.com` | 上一个接口失败时 |
| 划词翻译 | `api.mymemory.translated.net`（会把选中文字送出） | 选中文字点「翻译」 |

- **没有**账号体系、付费功能、遥测、崩溃上报，也不做自动更新或自行安装依赖。
- 音频与字幕缓存、学习数据都留在你的库里（`data.json` 与你指定的笔记目录）；断网后已缓存内容照常可用。
- 抓取到的网页正文会先经 `sanitizeHtml` 移除 `script/style/iframe/object/embed/form` 与所有 `on*` 属性、拦截 `javascript:` 链接，再写入阅读区。

### 访问库（vault）之外的文件

启用本地转写后，插件（**仅桌面端**，`isDesktopOnly: true`）会通过 Node 的 `fs` / `child_process` 读取你在设置里填写的目录，并启动本地 Python 进程。这些路径**完全由你手动填写、默认留空**，插件不会自行创建、下载或扫描它们。设置页「可选增强状态」会实时显示配置情况。除此之外，插件只读写 vault 内的笔记和 `.obsidian/plugins/pineapple-english/` 缓存目录。

### 市场安装只含三件套

Obsidian 社区插件市场只会下载 `main.js`、`manifest.json`、`styles.css`。核心功能（订阅、播放、逐句字幕、单句循环、变速、查词、生词本、易错词、错题本与连播、跟读录音、打卡统计、笔记与导出、数据备份）**全部可用**，不依赖任何外部文件。

以下为**可选增强**，市场安装不含对应脚本，缺失时自动降级：

| 增强 | 需要的额外文件 | 缺了会怎样 | 如何启用 |
|---|---|---|---|
| 本地 Whisper 转写 | `extras/transcribe.py` + 自备 Python / 模型 | 没有现成逐字稿的节目需手动粘贴 SRT/VTT，或用「按句长估算时间轴」 | 手工放置 |
| 常驻识别（跟读打分加速） | `shadow_server.py` | 退回逐句单次转写，首句慢几秒；**打分功能不失效** | 手工放置 |

启用方式：从本仓库源码或 Release 附件取得 `.py`，**手动**放进 `.obsidian/plugins/pineapple-english/`，再到「设置 → 本地转写」填 Python 解释器、脚本目录、模型目录。插件**不会**自动下载或安装这些文件（社区政策禁止插件自行安装依赖）。

### 第三方与许可

- 插件本体：MIT（见 `LICENSE`）。
- 语音转写：[faster-whisper](https://github.com/SYSTRAN/faster-whisper)（MIT）与 Whisper 模型，由用户自行安装，不在插件内分发。
- 词典 / 翻译：dictionaryapi.dev、有道、MyMemory 为第三方在线服务，各自适用其服务条款。
- 预置订阅源里的播客与 Newsletter 版权归各自作者；插件只读取公开 RSS，不托管、不转载其内容。

## 已知限制

- 字幕有没有时间轴取决于源站，没有就只能估算或手动粘贴
- 部分播客的「逐字稿」其实是节目简介，插件会用长度和结构判断后丢弃，宁可没有也不给假字幕
- 录音依赖浏览器麦克风权限；系统级音频设备异常时请用外部录音后「⬆ 导入」
- 中文界面，英文内容

## 上架与发布规范（维护者笔记）

本插件在 Obsidian 社区目录登记为 **Pineapple English Listening**；界面内的中文名「菠萝英语精听」保持不变。两个名字不同是有意的：`manifest.json` 的 `name` 必须符合目录的 Basic Latin 规则，界面文案则面向中文使用者。

- **版本事实来源**：默认分支 HEAD 的 `manifest.json`；`versions.json` 记录每个历史版本对应的最低 Obsidian 版本；`package.json` 的 `version` 必须与 manifest 一致。
- **打 tag**：严格 `x.y.z`，**不带 `v`**。用 `node version-bump.mjs 1.2.1` 一次同步三处版本文件，提交后再 `git tag 1.2.1 && git push origin 1.2.1`。
- **Release 附件**：只放 `main.js`、`manifest.json`、`styles.css` 三件；`.github/workflows/release.yml` 会校验 tag 与 manifest 版本一致并自动生成 Release。不要把 zip、`extras/`、模型或 `data.json` 放进附件。
- **无构建步骤**：`main.js` 既是源码也是产物，仓库文件与 Release 附件逐字节一致，目录的构建一致性检查天然通过。
- **仓库卫生**：`.gitignore` 已排除 `data.json`（私人学习数据）、`cache/`、`backups/`、录音、模型与本地打包产物。提交前请确认这些文件没有进入公开仓库。
- **首次提交流程**：注册并登录 `community.obsidian.md` → Profile 连接 GitHub（只读授权）→ Plugins → New plugin 填仓库地址 → 自动审核 Scorecard 的 error 清零 → Publish。之后每次更新只需发新 Release，目录会自动同步到客户端的社区插件列表。
